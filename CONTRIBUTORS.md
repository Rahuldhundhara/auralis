## Contributing

1. Clone `https://github.com/Rahuldhundhara/auralis.git` and create a branch.
2. Run `npm install`, then `npm run typecheck` and `npm run build` before pushing.
3. Open a pull request against `main` with a short description and test notes.

Collaborators with write access can push a branch directly:

```bash
git checkout -b fix/short-description
git add .
git commit -m "Describe the change"
git push origin fix/short-description
```

Then open the pull request link GitHub prints. `main` is not protected, but a
pull request keeps the change reviewable and keeps the history readable.
